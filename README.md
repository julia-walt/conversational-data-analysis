# LLM Conversation Data Analysis

This project explores a sample of conversational LLM data using Python and SQL.

The workflow includes:
- Loading and cleaning semi-structured JSON data
- Transforming and structuring the dataset with pandas
- Running SQL-based exploratory analysis
- Visualizing message length distributions
- Identifying basic structural patterns in conversational AI data

## Tools Used
- Python
- pandas
- SQLite
- matplotlib
- Jupyter Notebook
